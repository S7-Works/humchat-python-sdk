# Security reporting

For a suspected vulnerability, [submit a private report](https://github.com/S7-Works/humchat-python-sdk/security/advisories/new) to the repository maintainers. Use [public issues](https://github.com/S7-Works/humchat-python-sdk/issues) only for nonsensitive bugs and questions.

Include the affected SDK version, impact and a minimal reproduction using synthetic data. Do not include credentials, real message content or private deployment information. Keep vulnerability details out of public issues while the report is being assessed.

The SDK is an alpha preview. Production acceptance and package-index publication remain pending, and no supported-release maintenance schedule is established. A named security response owner, response-time commitment and support SLA remain unassigned. Providing a private reporting route does not establish production readiness or change the package's `UNLICENSED` status.
